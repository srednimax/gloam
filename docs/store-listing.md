# Play store listing copy

**This document is the only copy of the listing text.** The Console is where it is pasted, not where
it lives — a value that exists only in a web form cannot be reviewed, translated as a set, or
recovered when someone edits it by accident.

Three scripts read this file, so its headings are load-bearing:

| Script | Reads |
| --- | --- |
| `scripts/play-whatsnew.py` | the `## Release notes` section, rendering every locale's note in the one format the Console's textarea accepts |
| `scripts/notes-gate.py` | the newest `### x.y.z` heading, refusing a merge where it does not match `versionName` |
| `scripts/play-metadata.py` | the whole thing, generating the `fastlane/metadata/` tree the publish workflow uploads |

> **The gate exists because of a real failure.** A release shipped to production carrying the
> *previous* version's release notes: `versionName` had been bumped and the notes had not, nothing
> compared the two, and Play does not allow release notes to be edited on a live release. The
> correction had to wait for the next upload. Renaming a heading is cheaper.

### Full description — 2571/4000

```
Android's brightness slider stops at a floor. On most phones that floor is still too bright to read in a properly dark room. Gloam is the range underneath it.

HOW IT WORKS

Gloam takes the backlight down to the lowest level your phone allows, then draws a shade over the screen to go the rest of the way. One control moves both halves, from barely dimmed to very nearly dark.

WHAT YOU GET

- Dim past the floor. One slider, well below what the system lets you set.
- Warmth. A separate control that tints the screen amber, as far or as little as you like.
- Auto-off. Every shade you start gets a deadline, so you never unlock a phone you cannot read the next morning. Set it to Never if you would rather it stayed on.
- Works over everything. Other apps, the launcher, your browser, your reader.

EVERY FEATURE IS FREE

No ads. No account. No sign-up. No server. No subscription, no premium tier, and nothing behind a paywall. There is no paid version to keep alive, so a feature either ships to everyone or it does not ship.

NO NETWORK AT ALL

Gloam does not request the internet permission, so it cannot phone home even by accident. It remembers a dim level and whether the shade should be on. That is the whole of it.

WHAT IT CANNOT DO

Gloam does not make the screen emit less light than its backlight floor. No installed app can. That floor belongs to the display driver. Gloam gets the backlight down to it and puts a dark layer in front of it. The result reads far dimmer, but the panel is still lit.

System permission dialogs and some secure screens draw above every app's overlay by design, so they will appear at full brightness. That is Android protecting you from apps like this one, and it is working as intended.

The shade never takes your taps. Every touch passes straight through to whatever is underneath, and there is always an ongoing notification with a Stop button. An overlay drawn over every other app has to be impossible to get stuck behind.

Some phones stop it. Aggressive battery managers, Xiaomi's especially, will kill the service on their own. If the shade vanishes without you touching anything, that is the battery settings on your phone rather than Gloam.

Gloam is a dimmer. It makes no claim about your eyes, your sleep or your health.

PERMISSIONS

- Display over other apps. This is the whole mechanism. The shade is that window.
- Notifications. The ongoing notification is how you turn the shade off, and on Android 13 and up it does not appear until you allow it.

Open source, built in the open: github.com/srednimax/gloam
```

## Release notes (Play's "What's new", 500 chars per locale)

**Don't paste these by hand.** The Console takes all languages in one textarea, tagged by locale,
and `scripts/play-whatsnew.py` renders exactly that from the blocks below:

```bash
python3 scripts/play-whatsnew.py                 # newest version here, to stdout
python3 scripts/play-whatsnew.py --version 0.1.0 # a named one
```

It reformats and never retypes, so this document stays the only copy. It exits non-zero if a note is
over 500 characters, or if a language the **app** ships has no note at all — both of which Play
accepts in silence and a user then reads.

The label above each block is **parsed**, not decorative: `**<Language>** — <n>/500:` on a
line of its own, with the fenced note under it. The count is what keeps a note from reaching Play
truncated, and `play-whatsnew.py` refuses a language the app ships and this section does not.

**Write these about what changed for the person reading them.** A schema migration is not a release
note; the feature it made possible is. A release where nothing user-visible changed still needs a
heading — rename it and say so in one line, so the decision is deliberate rather than made by
default.
